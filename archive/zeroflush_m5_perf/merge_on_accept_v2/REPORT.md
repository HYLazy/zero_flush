# 50GB merge-ON 验收报告（2026-09-14，准入循环修复后）

> 基线：`e355d35`（安装顺序准入循环）+ `8fb5bab`（DB mutex 退避修复）
> 配置：`ZF_INSTALL_LOCK` 默认开启（=1）、merge ON、governance OFF、
>      16T / 1KB / 16 分区 / sampled / compression=none / seed=20260914
> 负载：`--num=48000000`（键空间 48M）`--writes=3000000`（每线程）
>      → **48M 次写 = 48GB 逻辑字节**（期望覆盖率 1-e⁻¹ = 63.2%）
> 对照：09-02 基线同规模 27,066 ops/s；历史 native 26,409 ops/s

## 结论：**通过**（不崩溃、不死锁、物化不停滞、WAL 可回收、数据完整）
